# Abdelhady Hassaan | Portfolio

An Arabic portfolio website with a working **CV Analyzer** tool.

**Live site:** https://abdelhadyhassaan-oss.github.io/portfolio/

## The CV Analyzer

Paste a CV (Arabic or English) and the tool:

- scores it out of 100
- checks for contact details, key sections (summary, experience, education, skills, projects), action verbs, and measurable results
- suggests what to add or improve
- lists the most repeated keywords

It uses simple rule-based checks and runs entirely in the browser, so the pasted text is never sent to a server.
